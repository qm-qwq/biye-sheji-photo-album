开场：各位老师好，我的毕设题目是《个人相册管理系统的设计与实现》。
登录：现在演示登录。系统采用 BCrypt 算法对密码进行哈希加密，确保数据安全（输入 admin / 123456 登录）。
新建相册：登录后进入个人主页。我新建一个相册，后端会自动绑定当前用户的 ID，实现数据的物理隔离（点击新建相册）。
上传照片：点进相册，选择一张 5MB 的高清图片上传。后端会自动截取缩略图，并按“用户ID/年月”存入服务器。
浏览与预览：列表页加载的都是几十 KB 的缩略图，非常快。点击缩略图，会通过 Modal 弹窗无缝加载原图，方便用户查看细节。
安全验证：如果其他用户登录，是绝对看不到我的相册和照片的，越权删除接口也会直接返回 400 错误。
结束：系统基于 Spring Boot 2.7 + MyBatis-Plus 开发，代码结构清晰，已完整部署上线。谢谢老师！
